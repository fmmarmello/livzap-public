# Code of Conduct

This project expects respectful, professional collaboration.

## Expected behavior

- Be direct and constructive.
- Focus criticism on code, design, documentation, and behavior.
- Respect differing experience levels and constraints.
- Avoid harassment, insults, threats, doxxing, or discriminatory language.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code of conduct. Repeated or severe violations may lead to blocked participation in the project.

Report conduct concerns privately to the maintainers when a private contact path is available.
